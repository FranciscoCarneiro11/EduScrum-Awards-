# EduScrum Awards

O **EduScrum Awards** é uma plataforma Full-stack concebida para digitalizar e otimizar a metodologia Scrum em ambiente académico. O sistema permite a gestão completa de disciplinas, equipas e avaliação de desempenho através de métricas visuais.

## Funcionalidades Principais

* **Painel de Administração:** Gestão centralizada de disciplinas, inscrição de professores e alunos.
* **Gestão de Equipas Scrum:** Professores podem formar e monitorizar equipas dinamicamente.
* **Dashboard de Performance:** Visualização de dados através de gráficos interativos para alunos e docentes acompanharem o progresso.
* **Sistema de Roles:** Permissões distintas para Administradores, Professores e Alunos.
* **Gestão de Backlog e Sprints:** Ferramentas para organizar o fluxo de trabalho das equipas.

## Stack Tecnológica

* **Frontend:** React com TypeScript (Interface reativa e tipada).
* **Backend:** Java SpringBoot (Lógica de negócio e persistência de dados).

## Estrutura do Projeto

* `/frontend`: Interface do utilizador.
* `/backend/awards/awards`: Núcleo da API desenvolvida em Java.

## Como Executar (Ambiente de Desenvolvimento)

### Backend (Java)
1. Navega até `backend/awards/awards`.
2. Certifica-te de que tens o Maven e o JDK instalados.
3. Executa o projeto através da tua IDE ou via terminal com `mvn spring-boot:run` (se aplicável).

### Frontend (React + TS)
1. Navega até a pasta `frontend`.
2. Instala as dependências: `npm install`.
3. Inicia a aplicação: `npm start`.
